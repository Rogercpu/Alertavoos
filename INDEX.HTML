</> Como conectar API real (Amadeus / SerpApi)

Para consultar tarifas reais automaticamente sem gastar a bateria do celular, conecte este aplicativo a uma API de voos:

  1. Amadeus for Developers (Grátis para testes): crie uma conta em developers.amadeus.com, gere sua API Key e API Secret e use o endpoint Flight Offers Search.
  2. SerpApi (Google Flights API): alternativa simples em serpapi.com que retorna os preços diretos do Google Voos em JSON.
  3. Automação em segundo plano: use n8n ou Make para rodar a consulta a cada 1h/3h e enviar push via Firebase quando preco >= X && preco <= Y.
Ponto de integração no código: 
const FLIGHT_API_CONFIG = {
  provider: "amadeus", // ou "serpapi"
  apiKey: "SUA_CHAVE_AQUI",
  currency: "BRL"
};
